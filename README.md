# Binaural Studio

集中（ポモドーロ）と瞑想のためのバイノーラルビート生成アプリ。
音はすべてブラウザ内で合成し、音源ファイルも通信も使わない。

仕様は [docs/SPEC.md](docs/SPEC.md) にあります。

## 使い方

```bash
npm install
```

```bash
npm run dev
```

http://localhost:5273 を開く。**ヘッドホンで聴いてください**（左右で異なる音を鳴らす仕組みのため、スピーカーでは効果が出ません）。

初回は「ヘッドホン確認」で左右の向きと 6 Hz のうなりが聞こえるかを確認しておくと、以降の体験が安定します。

| Phase | 内容 | 状態 |

| 1 | バイノーラルコア・フェード・25 分タイマー・Home / Session 画面 | 完了 |
| 2 | 環境音レイヤー（雨・波・パッド）+ リバーブ | 完了 |
| 3 | Δf カーブ編集・ポモドーロ・チャイム・WakeLock / MediaSession | 完了 |

環境音は 11 種すべて実装済みです（ブラウン / ピンクノイズ・部屋の空気感・雨・波・
温かいパッド・森と小川・焚き火・シンギングボウル・ドローン・純音のみ）。

**オフラインで動きます。** 一度読み込めば、通信が無くても全機能が使えます
（音は端末内で合成しており、外部リソースを一切使っていないため）。
ブラウザの「アプリとしてインストール」からホーム画面に置けます。

## 設計上の要点

- **位相の純度**：搬送波バスには、左右を混ぜる処理（リバーブ・コンプ・モノ化）を一切通さない。
  リバーブを最大にし環境音を重ねた状態でも、左右の周波数差が Δf ± 0.00002 Hz、
  チャンネル間相関 0.000 であることを実測で確認済み。
- **音高を持つレイヤーは搬送波と干渉しない位置に置く**：パッドは三角波（奇数倍音のみ）を
  fc の 0.5 / 0.75 / 1.5 倍で鳴らすとどの倍音も fc に一致しない（実測 −58.8 dB）。
  シンギングボウルは非整数倍音を fc の 0.5 倍に基音を置いて −68.1 dB、
  ドローンは倍音を持たないサイン波を fc の 0.25 倍に置いて −46.7 dB。
- **粒はブロック単位でバッファに焼く**：粒ごとにノードを作るとオフラインレンダリングが
  壊滅的に遅くなる（60 秒の雨に 14 秒）。実測で 1500 倍速くなり、リアルタイムのノード生成も激減した。
- **レベルは RMS 基準で校正**：各レイヤーのソースを RMS = 1.0 に正規化し、
  level=1 での出力 RMS が基準値と一致することをオフラインレンダリングの実測で確認する。
- **書き出しは 120 秒ずつ分割して描画**（25 分一括では 576 MB、135 分では 3.1 GB になるため）。
  境界は搬送波の累積位相を解析的に繋ぎ、ノイズ・LFO・雨粒をセッションの絶対時刻に整列させることで、
  分割しても一括描画と −37 dB 以内で一致し、クリックも出ない。
  25 分の書き出しは実測 96.8 秒。

## 書き出し

ホームの「WAV で書き出す」から。16 / 24 bit、48 kHz ステレオ。
25 分 16 bit で 288 MB です（見積を画面に出します）。
ループ再生用に、フェードを省いて環境音のループが揃う長さに丸めるオプションもあります。
- **時間源はオーディオクロックのみ**：`AudioContext.currentTime` を唯一の正とし、
  `setInterval` は表示更新と先読みスケジューリングのトリガにしか使わない。
  タブを裏に回しても音とカウントがずれない。
- **クリックを鳴らさない**：すべての変化は AudioParam のランプで表現する。
  セグメント境界を含む全区間で、隣接サンプル差分が純音の理論上限以下であることを実測で確認済み。
- **等ラウドネス補正**：搬送波が低いほどゲインを持ち上げ、帯域を変えても体感音量が変わらないようにする。
- **セーフティは WaveShaper のソフトクリッパー**：`DynamicsCompressor` は圧縮していなくても
  内部メイクアップゲイン（Chrome 実測 約 +2 dB）が掛かるため使わない。
